# Пульты для кондиционеров (iQOO Neo 10)

- `app/` — **Пульт Hisense** (протоколы Kelon 48 / 168 бит)
- `chigo/` — **Пульт Chigo** (пульты ZH/LT-01 и ZH/JG-01, раскладка по Arduino-HeatpumpIR)

Готовые APK — в разделе Releases.

## Пульт Hisense

Приложение превращает ИК-порт телефона (в блоке камеры) в пульт кондиционера Hisense.

## Что умеет
- Включение / выключение
- Температура 16(18)–32 °C, большой круговой индикатор
- Режимы: авто, охлаждение, обогрев, осушение, вентиляция
- Вентилятор: авто / низкий / средний / высокий
- Качание жалюзи, режим сна, турбо, подсветка дисплея (протокол B)
- Запоминает последнее состояние, вибрация при нажатии
- Без рекламы, интернета и лишних разрешений (только `TRANSMIT_IR`)

## Как получить APK без компьютера (через GitHub)
1. Зарегистрируйтесь на github.com и создайте новый репозиторий (можно приватный).
2. «Add file → Upload files» — загрузите **содержимое** этого архива (папки `app`, `.github` и файлы из корня).
   Папку `.github` браузер на телефоне может не показать — если так, создайте файл вручную:
   «Add file → Create new file», имя `.github/workflows/build.yml`, вставьте текст из архива.
3. Откройте вкладку **Actions** → «Build APK» → дождитесь зелёной галочки (~3–5 мин).
4. Внизу страницы сборки, в разделе **Artifacts**, скачайте `HisenseRemote-apk` (zip), распакуйте, установите `.apk`.
   При установке разрешите «Установку из неизвестных источников».

## Как собрать на компьютере
Откройте папку в Android Studio → Build → Build APK(s). Или: `gradle assembleRelease` (Gradle 8.10+, JDK 17).

## Первый запуск
1. Направьте верх телефона на кондиционер.
2. Нажмите ⏻. Кондиционер пискнул — готово.
3. Нет реакции — внизу выберите другой протокол (A или B) и повторите.

**Протокол A (48 бит)** — кнопка питания переключает состояние. Если индикатор в приложении
разошёлся с реальностью, удерживайте ⏻ — индикатор исправится без отправки сигнала.

**Протокол B (168 бит)** — передаёт всё состояние сразу (как пульты DG11R2-01 / RCH-R0Y3).

Протоколы основаны на открытой библиотеке IRremoteESP8266 (ir_Kelon.cpp) и проверены
на эталонных записях пультов.
